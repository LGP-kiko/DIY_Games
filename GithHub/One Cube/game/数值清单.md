# OneCube 数值清单（可同步）

> **下面 ```tune 块就是唯一权威数值源。** 在这里改数字 → 运行 `同步数值.ps1` → 自动回写进 `game/OneCube.html`（先备份、再语法校验）。
>
> ```powershell
> powershell -ExecutionPolicy Bypass -File 同步数值.ps1          # 预览：报告每个 key 的「旧值 → 新值」，不改文件
> powershell -ExecutionPolicy Bypass -File 同步数值.ps1 -Apply   # 实际写入 + 自动备份 + node --check 校验
> ```
> （本机没有 `pwsh`，且默认策略禁止运行脚本，所以必须用上面的完整命令。）
>
> 行内 `#` 之后是注释；新增可调项时在 `同步数值.ps1` 的 `$MAP` 里补一条 `'key' = '正则'`（正则的第一个捕获组圈住数值本身）。

```tune
# ── 1. 逻辑与物理 ─────────────────────────────
PHY.G          = 10        # 重力（格/秒²）
PHY.MAXSPEED   = 3         # 水平最大速度
PHY.ACC        = 8         # 加速度
PHY.JUMP_H     = 1.5       # 跳跃高度（格）
PHY.HALF       = 0.285     # 玩家碰撞半宽
CROSS_GATE     = 0.1       # 跨面归位门槛（中心越出该值才切换 face）

# ── 2. 相机 ───────────────────────────────────
cam.yaw        = 0         # 初始水平角
cam.pitch      = 0.4       # 初始俯仰角
cam.dist       = 12        # 初始距离
orbit.sens     = 0.006     # 中键自由视角灵敏度（rad/像素）

# ── 3. 计分 ───────────────────────────────────
score.init     = 2000      # 初始分
score.shoot    = 800       # 每次射击消耗
score.warn     = 400       # 低分警戒（闪烁 + 提示音）
score.bonusRed = 100       # 清红障奖励
score.bonusBlue= 200       # 清蓝障奖励
score.bonusBlk = 400       # 清黑(灰)障奖励
score.portal   = 1000      # 每关首次使用传送门奖励

# ── 4. 子弹 / 弹道残影 / 粒子 ──────────────────
bullet.speed   = 30        # 子弹速度（格/秒）
bullet.life    = 3         # 子弹寿命（秒）
trail.life     = 0.1       # 弹道残影每点存活（秒）
trail.step     = 0.0625    # 残影点间距（格）= 4 贴图像素 = 角色眼睛大小
trail.px       = 4         # 残影方块边长（贴图像素）
fx.life        = 0.45      # 粒子寿命（秒）
fx.px          = 6         # 粒子方块边长（屏幕像素）
fx.n           = 14        # 每次爆发粒子数
fx.spd         = 170       # 初速（屏幕像素/秒）
fx.drag        = 0.86      # 每帧阻尼
fx.g           = 60        # 粒子重力（屏幕像素/秒²）

# ── 5. UI ─────────────────────────────────────
slice.px       = 4         # 九宫格切角框：像素单位
slice.sh       = 4         # 九宫格切角框：投影偏移
ui.btnW        = 158       # 次按钮宽度（地图编辑器/输入分享码）；主按钮 #btn-start 独立为 168
ui.cardSize    = 96        # 选关卡片边长（正方形）
ui.perPage     = 15        # 选关每页数量（5 列 × 3 行）
```

## 附：不在 tune 块里的（属于结构而非数值）

| 项 | 值 | 说明 |
|---|---|---|
| 面格贴图 | 64 贴图像素/格 | 改这个要动面贴图生成与所有尺寸换算 |
| 角色贴图 | 16×16（占 1 格） | `game/mats/character.png` |
| 字体 | 方舟像素 12px 比例版，子集 963 字 | 内嵌 WOFF2 base64；字号族 12 / 24 / 36 / 48 |
| 九宫格 tile | `SL=PX*2+SH=12` → tile 36×36 | 由 slice.px / slice.sh 推导 |
| 配色 | THEME（JS）+ `:root`（CSS） | 见下表 |
| 内置关卡 / 文案 / 调色板 | 数据 | 不属于"参数" |

## 附：游戏时 / 调试时的区分点（共 9 处，均以 `window.dbgMode` 分支）

| 位置 | 游戏时 | 调试时 |
|---|---|---|
| 地刺致死 | 正常致死 | 无敌 |
| 障碍致死 | 正常致死 | 无敌 |
| 分数归零致死 | 正常致死 | 不判定 |
| 得分显示 | 显示分数 | 隐藏整个得分块 |
| 射击扣分 | 扣 800、检查余额 | 免费、不检查 |
| 倒计时音效 | 有 | 无 |
| 钥匙通关 | 触发通关 | **不触发** |
| Q/E 按键 | E = 使用传送门 | 旋转当前面状态 ±90° |
| 相机 | 正常跟随 | 保持跟随（吸附分支未启用） |

**跨作用域约定**：游戏代码分 **逻辑块 / 渲染块** 两个作用域，互不可见。状态挂 `window`（如 `dbgMode`），数组按参数传递（如 `stepBullets(…, trails, bursts)`），跨块调用走单一出口（如 `window.dbgExit`）。
