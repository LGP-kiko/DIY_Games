### 8.2　伤害与护甲公式（P0，逐字取自 `Input\一叶.docx`）

《一叶》的战斗模型只有**两种伤害类型**与**两个维度的护甲等级**，全部伤害都通过下式结算，并**必须实现为查表**。

| 项目 | 规定 |
| --- | --- |
| 伤害类型 | **轻型（light，对单）** 与 **重型（heavy，对群 AOE）**，共两种 |
| 护甲等级 | 每个单位持有两个独立等级，取值 **0–5**：轻型护甲等级、重型护甲等级 |
| 抗性描述 | 对外显示格式固定为「轻型护甲数字 / 重型护甲数字」，例如建筑单位为 `3/3` |
| 轻型公式 | `max( min(6 - n, x), x * (1 - 0.1n) - n )` |
| 重型公式 | `n = 0 时取 x；n ≥ 1 时取 x * 5 / (5 + n!)` |
| 符号含义 | `n` = 目标**对应维度**的护甲等级（受轻型攻击取轻型护甲等级，受重型攻击取重型护甲等级）；`x` = 武器基础伤害 |
| 取整 | 结果向下取整，最小 1 |
| 优化要求 | 运行时禁止进行公式运算，必须查预计算表（基础伤害 **1–200** × 护甲等级 0–5，共 2 × 1200 个格子，覆盖全部 33 种武器） |
| 重型溅射 | 所有重型武器都带溅射半径；命中点全额，边缘 25%，中间线性衰减 |
| 友军溅射 | 对己方单位按 50% 结算；对己方建筑**不结算** |
| 战争单位 | 不受到任何正面或负面特殊效果影响：老兵、护盾、再生、吞噬、腐蚀、解放全部无效 |

> **设计含义（实施方必须理解，否则会把数值调坏）**：轻型护甲每提升 1 级，受到的轻型伤害约再降 10% 并额外减 n 点，同时保底伤害为 `min(6-n, x)`；重型护甲对 AOE 的削减是**阶跃式**的——3 级只剩 45%，4 级只剩 17%，5 级只剩 4%。因此**重型护甲是抵御范围伤害的核心手段**，轻型护甲只提供平滑的线性减伤。建筑统一 3/3，意味着拆建筑必须靠轻型高伤或大量重型叠加，不能被一发 AOE 抹平。
