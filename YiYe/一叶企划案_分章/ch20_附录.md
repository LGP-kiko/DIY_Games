### 20.3　附录 C：核心数据结构定义（TypeScript 风格）

> **权威性说明（P0）**：本附录是第 16 章《存档与回放》中数据结构定义的**精简参考版**。冲突时**以第 16 章为准**；与第 2 章的 PRNG / 坐标规范冲突时以第 2 章为准。

```ts
type Faction = 'PRIMORDIAL' | 'DOMINATOR' | 'EROSION' | 'CHAOS';
type DamageType = 'light' | 'heavy';
type MoveType = 'foot' | 'track' | 'wheel' | 'hover' | 'air';
type UnitKind = 'general' | 'building' | 'war' | 'slave';
type Stance = 'Aggressive' | 'Defensive' | 'HoldGround' | 'HoldFire';

interface Armor { light: number; heavy: number; }        // 各 0..5；UI 显示为 `${light}/${heavy}`

interface Entity {
  id: number;                    // 全局单调递增，实体数组按此升序维护
  kind: UnitKind;
  type: string;                  // 数据表键名
  owner: number;                 // playerId；混沌为 -1
  faction: Faction;
  x: number; y: number;          // 运行时世界坐标（浮点，单位=格）；存档时 ×1000 取整
  z: number;                     // 高度层 0..4
  hp: number; maxHp: number;
  armor: Armor;
  facing: number;                // 0..7
  turretFacing: number;          // 0..7
  veterancy: 0 | 1 | 2;          // 战争单位恒为 0
  kills: number;
  stance: Stance;                // 战争单位恒为 'Aggressive'；奴隶不适用
  state: string;
  cooldown: number;
  orderQueue: Order[];
  targetId: number | null;
  lastAttackerId: number | null;
  lastHitTick: number;
  dead: boolean;
  // 经济
  cargo?: number;                // 采集单位携带的源质
  // 主宰专属
  shield?: number; shieldMax?: number; outOfCombatTick?: number;
  // 侵蚀专属
  stealthCharge?: number; stealthed?: boolean;
  // 侦查
  burrowed?: boolean;
  // 原初专属
  devourCount?: number;
  // 奴役
  isSlave?: boolean; liberatedFrom?: number | null; controllingNodeId?: number | null;
  // 混沌专属
  chaosScale?: number;           // 0.8..1.6
  // 建筑
  size?: [number, number];
  progress?: number;             // 施工 / 生产进度 0..1
  rally?: { x: number; y: number } | null;
  queue?: QueueItem[];
  powered?: boolean;             // 仅主宰
  powerOut?: number; powerUse?: number;   // 仅主宰
  salvageValue?: number;         // 主动回收可返还的基数（= floor(cost × 0.5)）
}

interface Order { cmd: string; x?: number; y?: number; targetId?: number; tile?: number; }

interface Corpse {                 // 残骸（本作特有的核心对象）
  id: number;
  x: number; y: number;
  sourceType: string;              // 原始单位键名（用于悬停显示）
  sourceName: string;              // 原始单位中文名
  maxHp: number;                   // 携带的「最大体力」信息
  cost: number;                    // 携带的「初始造价」信息
  spawnTick: number;
  expireTick: number;              // spawnTick + 1200
  salvageable: boolean;            // 战争单位的残骸为 false（可被吞噬但不可回收）
  devourable: boolean;             // 恒为 true
}

interface ChaosLair {
  id: number; x: number; y: number;
  scale: number;                   // 0.8..1.6
  alive: boolean;
  spawnedIds: number[];            // 已刷新的守护单位（巢穴被摧毁后不再刷新）
}

interface Player {
  id: number; faction: Faction; isAI: boolean; difficulty?: 0 | 1 | 2 | 3;
  essence: number;
  powerOut: number; powerUse: number; lowPower: boolean;   // 仅主宰有意义
  pop: number; popCap: number;                              // 奴隶不计入 pop
  kills: number; losses: number;
  essenceHarvested: number; essenceSalvaged: number; essenceEarned: number;
  unitsLiberated: number; devourCount: number;
  peakPopulation: number; buildingsBuilt: number; unitsTrained: number;
  fog: FogMap;
  controlGroups: number[][];       // 9 组
  selection: number[];
  plunderFlags: Record<string, boolean>;  // 侵蚀的「腐蚀掠夺」达成标记
}

interface World {
  tick: number; mapW: number; mapH: number;
  terrain: Uint8Array; height: Uint8Array; ore: Uint16Array;
  blocked: Uint8Array; buildable: Uint8Array;
  moveCostFoot: Uint16Array; moveCostTrack: Uint16Array;
  blockVersion: number;
  entities: Entity[]; nextId: number;
  corpses: Corpse[];
  chaosLairs: ChaosLair[];
  players: Player[];
  rng: { map: Rng; combat: Rng; ai: Rng; fx: Rng; ambient: Rng };  // 仅前三条参与哈希
  projectiles: Entity[];
  triggers: TriggerState[];
  winner: number | null;
}

interface Rng { next(): number; int(n: number): number; range(a: number, b: number): number; chance(p: number): boolean; getState(): number; setState(v: number): void; }
```

### 20.4　附录 D：常见实现陷阱 FAQ

| 问题 | 症状 | 正确做法 |
| --- | --- | --- |
| **把 `min(6-n, x)` 当成伤害上限** | 高护甲单位变得完全无敌 | 它外层是 `max`，是**保底值**（见 8.2） |
| **实时套伤害公式** | 回放不一致，且违反设定「优化：使用查表」 | 启动时预计算 6×200 两张表，运行时只查表（9.5） |
| **只给武器做一张查表** | 伤害类型切换时取错护甲维度 | 轻型武器查 `lightArmor`，重型武器查 `heavyArmor`（9.5） |
| 用 `deltaTime` 驱动逻辑 | 高刷屏上单位跑得更快 | 固定步长累加器（2.4） |
| 用 `Math.random()` | 存档 / 回放不可复现 | 五条 PRNG 流（2.5） |
| **给原初或侵蚀加了电力** | 阵营机制被抹平，主宰失去身份 | 电力只属于主宰；另两阵营的 UI 不显示电力条（6.5） |
| **让战争单位吃到老兵 / 护盾 / 再生** | 违反设定原文，战争单位变成「超级兵」 | `kind === 'war'` 时跳过一切加成与减益（9.6） |
| **让玩家框选到奴隶** | 玩家以为能指挥，实际无响应，体验极差 | 奴隶不进选择集合；点击只弹信息（4.4、13.3） |
| **残骸只做特效不做数据** | 侵蚀失去第二经济、混沌无法回血 | 残骸必须携带 `maxHp` 与 `cost`，且进存档与哈希（6.6） |
| **残骸与死亡不同帧生成** | 侵蚀的自动回收偶尔漏掉 | 死亡结算与残骸生成必须在同一 tick（9.1） |
| **解放只在 UI 层表现** | 奴隶换了颜色但仍归原主 | 解放必须在阶段 11 真正改 `owner`（9.1） |
| **混沌对侵蚀主动开战** | 违反「不被中立单位敌对」 | 混沌索敌时排除侵蚀，除非该单位已被侵蚀攻击过（9.2） |
| **混沌中心强化只加体力** | 玩家感受不到「越靠近中心越强」 | 体力、伤害、护甲等级**同时**乘 `scale`（9.6） |
| **主宰奴隶占人口** | 主宰的经济优势消失 | 奴隶 `pop = 0`（8.5） |
| 每帧重建地形 | 帧率暴跌 | 地形分块预渲染（3.6） |
| 单位叠成一坨 | 观感极差 | 阵型槽位 + 分离力（10.3、10.4） |
| 寻路每 tick 全量重算 | tick 超时 | 8 条/tick 预算 + LRU 缓存（10.2） |
| **浅毒滩允许履带通行** | 「载具必须走桥」的地图设计全部失效 | 浅毒滩仅 `foot` 与 `hover`（5.3） |
| **毒瘴被地面单位穿过** | 同上 | 毒瘴仅 `hover` 与 `air`（5.3） |
| **脉络 / 岩桥被建造** | 地图通路被建筑堵死 | 二者 `buildable = false`（5.2、5.4） |
| 用浮点坐标直接进存档 | 读档后位置漂移、哈希不一致 | 存档时 ×1000 取整（16 章） |
| 用 `btoa` 存中文存档 | `InvalidCharacterError` | `TextEncoder` + 自写 base64（16 章） |
| 用 `setTimeout` 调度音乐 | 后台标签页被节流 | `AudioContext.currentTime` 前瞻调度（14 章） |
| 语音播报刷屏 | 「基地遭受攻击」连播 20 次 | 同 key 节流（13.9、14.8） |
| 屏幕外音效同样大声 | 嘈杂、无法定位 | 按屏幕 x 计算 pan 与距离衰减（14 章） |
| 奴役单位的锁链图标漏画 | 玩家误判可指挥 | 全部奴隶常驻锁链图标（3.3） |
