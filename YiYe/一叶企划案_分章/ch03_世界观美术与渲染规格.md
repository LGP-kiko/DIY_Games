## 3　世界观美术与渲染规格

### 3.1　世界观与阵营设定

**背景（逐字取自 `Input\一叶.docx`）**：世界树养育叶片万千，然而并非每一片，都容得下生灵。「原初」是幸运的——当他们睁开眼，脚下一片丰沃。作为此处唯一的种族，它以近乎野蛮的速度繁衍、蔓延，很快便占尽了这片天地。可威胁从不只在眼前：遥远的某处，另一片叶子正在凋零，那里诞生过一个名为「主宰」的文明——他们攀上了顶点，也最先嗅到了终末的气息。主宰之叶终将枯萎，于是他们向四方伸出触手，试图为自己的文明续上一缕火种。而原初之叶，早已被写进那份名单。战争没有悬念：身为末世文明的主宰，以碾压般的姿态抹平了原初在地表的一切——城邦、图腾、纪年，尽数归零。濒死的原初退入地底，那里毒瘴横流、熔岩流窜、暗无天日，他们只能选择与之融合，把恶劣本身炼进自己的血骨。而主宰终究是外来者——原初之叶排斥他们：地表生存尚且需要丰厚底蕴的支撑，攻入地底的部队则全军覆没。于是僵局落定，天各一方。双方都以为，故事会就此不了了之。直到那一天，原初挖穿了叶底。而叶底之下，从来不是虚无。

> **游戏内不出现任何过场叙事**。世界观通过**地形（毒瘴、叶底裂隙）、建筑形态、单位命名与播报语气**传达。三方势力在同一张叶面上争夺，混沌则不属于任何文明。

### 3.2　美术风格总纲（P0）

整体风格定义为**「有机工业」（Organic Industry）**：原初与侵蚀一侧是**湿润、有机、不规则**的（生物膜、菌毯、孢子、熔核），主宰一侧是**干燥、金属、几何**的（合金板、能量槽、铆钉、护盾网格）。平涂色块 + 2 像素深色描边 + 单侧高光块 + 硬边阴影，不使用渐变贴图与照片纹理。

| 绘制规则 | 规定 |
| --- | --- |
| 描边 | 统一 2 像素 `#12161c`（缩放前），只描外轮廓 |
| 阴影 | 落地椭圆阴影 `rgba(0,0,0,0.28)`，宽 = 精灵宽 × 0.8，高 = 宽的 30% |
| 高光 | 仅受光面（屏幕左上）加 1–2 像素亮色带，亮度 +18% |
| **原初的形状语言** | 圆润、不对称、有机曲线；外轮廓带 1 像素的生物膜亮边；建筑底部有菌毯晕染 |
| **主宰的形状语言** | 方正、倒角、几何对称；外轮廓为硬直线；建筑带能量槽（发光细线）与铆钉点 |
| **侵蚀的形状语言** | 下垂、撕裂、滴落；外轮廓带 1–2 像素的不规则齿状；建筑底部有腐蚀残渍 |
| **混沌的形状语言** | 无固定形状：多眼、多肢、随机凸起；同一类型的三个实例外形应有可见差异（用 `RNG.map` 决定） |
| 禁止 | 禁止渐变填充、禁止大面积 `shadowBlur`（仅爆炸与能量特效允许）、禁止位图纹理、禁止 Emoji |
| 朝向 | 每个单位预渲染 8 个朝向（0=正东，逆时针每 45° 一档） |
| 阵营着色 | 精灵的「阵营色区域」用 `tint(baseBitmap, factionColor)` 重新着色：保留明度，替换色相与饱和度（亮度 < 0.25 的像素视为描边不改） |
| 受损表现 | 体力 > 66% 正常；33–66% 叠加 2–3 处破损斑；< 33% 破损斑 + 每 0.5 秒冒烟（原初为渗出的绿雾，侵蚀为紫雾，主宰为电火花） |
| 护盾表现 | 主宰带护盾的单位在外围绘制一圈六边形网格（`#7aa8ff`，α 随护盾余量变化）；护盾破碎时播放网格碎裂 |
| 战争单位 | 体型明显大于同级单位（约 1.6 倍占据像素），外围常驻一圈金色描边以表达「免疫特殊效果」 |

**高度与叶底裂隙渲染（P0）**：地图每格有 `z ∈ [0,4]`。相邻格高差 > 0 时，在低格一侧绘制侧面墙体，颜色取高格地形色 × 0.7 明度。高差 ≥ 2 该边不可通行且不可建造；高差 = 1 时 `foot` 可攀爬（速度 × 0.6），`track`/`wheel` 不可通行。**坡道格**（`vein` 且高差 = 1）所有地面单位可通行。

> **浅毒滩与毒瘴是本作最重要的美术分界**：玩家必须能在 0.5 倍缩放下仅凭颜色就分辨「这里步兵能过、载具不能过」（浅毒滩）与「这里只有悬浮和空军能过」（毒瘴）。

### 3.8　视觉验收要点（P0）

- 把画面缩放到 0.5 倍时，仍能**一眼分辨**：己方 / 敌方 / 中立（混沌）、原初 / 主宰 / 侵蚀、建筑 / 步兵 / 载具 / 空军、残骸的位置、混沌巢穴、以及「浅毒滩 vs 毒瘴」的通行差异。
- 200 单位同屏混战时，玩家能通过选中圈、血条与**抗性描述徽标**找到自己刚框选的部队。
- 同一画面内不允许出现 3 种以上饱和度过高的颜色；爆炸、能量与源质是唯一的高饱和亮点。
- **残骸必须在混战中被看清**：残骸使用低亮度、低饱和的「尸体剪影」造型，与活着的单位形成明确区分，否则侵蚀玩家无法在战场上找到自己的收入来源。
- **奴役单位必须一眼可辨**：奴隶头顶常驻锁链图标，色调明显灰于普通单位，避免玩家误以为自己可以指挥它们。
- 所有 UI 文字在 1080p 下清晰可读，最小字号 12 像素（CSS 像素），数字使用等宽字形。
